# CodeAlpha Retail Sales – Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales performance, profitability, regional trends, product performance, and monthly sales patterns.

The project was completed as part of the **CodeAlpha Data Analytics Internship**.

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify the highest-performing regions
* Find top-performing product sub-categories
* Analyze monthly sales trends
* Understand business performance using data visualization
* Generate meaningful business insights from the dataset

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code
* GitHub

## 📊 Key Business Insights

* **Total Sales:** ₹14,956,982
* **Total Profit:** ₹3,747,121.20
* **Profit Margin:** 25.05%
* **Highest Sales Region:** West
* **Highest Sales Sub-category:** Health Drinks
* **Highest Profit Sub-category:** Health Drinks
* **Highest Sales Month:** September 2018

## 💡 Business Findings

The analysis shows that the **West region** generated the highest total sales among the available regions.

Among product sub-categories, **Health Drinks** recorded the highest sales as well as the highest profit.

The monthly analysis shows that **September 2018** recorded the highest monthly sales during the analyzed period.

The analysis also highlights the importance of monitoring regional and product-level performance to identify high-performing areas of the business.
